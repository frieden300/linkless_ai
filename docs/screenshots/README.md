# Screenshots directory

Drop app screenshots here. Recommended filenames (referenced in README.md):

- `chat_markdown.png`  — main chat view with Markdown response
- `vision_mode.png`    — image attached + vision model response
- `doc_rag.png`        — PDF/DOCX attached + document Q&A
- `settings.png`       — Settings screen with model switcher

Images should be 1280×800 px or similar 16:10 ratio for clean 2-column table display in the README.
